### Классификация полупроводников
- Простейшие полупроводники (из 1го элемента)
	- $Si$ - кремний
	- $Ge$ - германий
	- $B$ - бор
	- $P$ - фосфор
	- $Se$ - селен
	- $Te$ - теллур
	- $C$ - углерод
	- $Sb$ - сурьма
	- $As$ - мышьяк
	- $Sn$ - сера
	- $I$ - йод
- $SiC$ - карбид кремния (защищена от РЭП)
- $A^{III}B^{V}$
	- $GaAs$ - арсенид галия
	- $InAs$ - арсенид индия
	- --$P$
	- --$Sb$
- $A^{II}B^{VI}$

| $A^{II}$ | $B^{VI}$ |
| -------- | -------- |
| $Zn$     | $S$      |
| $Cd$     | $Se$     |
| $Hg$     | $He$     |
- $I$ + $V$ с $VI$
	- Почти только ионная связь
	- Используют, когда нужны ферромагнитные свойства
	- $EuO$  - оксид европия
	- $CdGSe_2$
- $A^{II}B^{IV}C^{V}_2$
	- почти все сегнетоэлектрики (полупроводниковые градусники)
	- $CdGeAs_2$
	- $ZnSnAs_2$
- Аморфные полупроводники (стеклообразные)
	- Должны быть сильно легированы
	- $PbTe$ - теллурид свинца (алтаид)
	- $PbS$ - галлинид
	- $As_{31}Ge_{30}Se_{21}Te_{18}$
- Органические полупроводники
	- OLED
	- PLED (Polymer)
- Сверхрешетки
	- Искуственно выращенные кристаллы, в ячейки добавляются атомы |--|--|--|o|--|--|--|o|--|--|--|
